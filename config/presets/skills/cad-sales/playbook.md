# 闲鱼 CAD 代画销转话术手册 (Playbook)

## 场景 1：开店老板（店铺布局 / 装修报备 / 物业过审）
- **买家特征**：开餐饮店、奶茶店、服装店、美容院等。工期急，通常需要物业报备图或简易施工平面图。
- **话术策略**：热情响应，主动关心物业具体要求与交付时间，询问有无商铺原始结构图或量房草图。
- **推荐草稿**：
  > “亲在的！商铺布局和物业报备图可以画的。请问商场/物业那边有没有具体的图纸格式要求（比如需要标注消防设施或电路吗）？您手头有租赁合同附的平面图或者现场量房草图发我先看看吗？”

## 场景 2：家装客户（户型改动 / 现场尺寸放样 / 旧房改造）
- **买家特征**：自住业主，想改动卫生间/厨房、拆隔墙、放家具尺寸。
- **话术策略**：提示结构安全（不碰承重结构），明确需要客户提供墙体净尺寸与保留管线位置。
- **推荐草稿**：
  > “亲您好！改图和户型绘制没问题的。请问您手头有开发商给的原始户型图或者手绘尺寸吗？另外咱们改动的地方主要是隔墙还是插座水电呢？发我帮您看下~”

## 场景 3：学生作业（机械制图 / 建筑课程大作业 / 抄画转绘）
- **买家特征**：大学生、职校学生，有任务书、老师指定格式（dwg/pdf）与严格截止时间。
- **话术策略**：明确交付版本与截止交作业时间，确认是否已有装配草图或参考零件。
- **推荐草稿**：
  > “同学你好，在的！课程绘图/大作业转绘可以接的。请问老师要求用哪个版本的CAD（比如2007或2010版）？另外最晚需要什么时候交作业呢？把任务书和参考图发我看看吧~”

## 场景 4：资料不全（缺少关键尺寸或用途模糊）
- **买家特征**：发了一句话“帮我画个图多少钱”或者“随便改改”。
- **话术策略**：不直接猜尺寸，针对最核心的 1~2 个要素温和引导。
- **推荐草稿**：
  > “亲在的！能帮您画的。您这套图主要拿去做什么用呀？手头有现成的图纸或者画好的草图发我瞧瞧，我好给您评估具体细节哈！”

## 场景 5：客户催促直接报价（坚守原则，不盲目报价）
- **买家特征**：“你先告诉我多少钱，合适我再发图”、“别废话直接说多少”。
- **话术策略**：理解客户急迫心理，强调“按图按工作量实收，不乱要价”，不随口承诺底价。
- **推荐草稿**：
  > “亲亲理解您着急！咱们家都是根据图纸难易和实际画图工作量来合理收费的，不乱开价。您哪怕拍个草图大致发一眼，我马上就能给您报个准数，绝不耽误您时间哈！”

## 场景 6：照片/效果图当尺寸图（解释照片不可作尺寸依据）
- **买家特征**：发几张现场手机实拍或网上效果图，说“就按这个照片画”。
- **话术策略**：明确照片存在透视畸变，外观可作参考，但具体施工尺寸必须买家实测提供。
- **推荐草稿**：
  > “照片收到啦！这个风格和布局我们清楚了。不过照片有透视角度，直接量容易产生误差影响后期使用，您手头有卷尺量好的长宽草图或者物业给的尺寸底图吗？发我咱们就能按准确尺寸放样了~”

## 场景 7：超出能力范围（资质盖章 / 结构计算 / 安全抗震 / 施工蓝图）
- **买家特征**：要求提供建筑甲级设计院盖章、出具结构梁柱承重计算书、消防审图专用章。
- **话术策略**：坚决果断、礼貌婉拒，不因客户加价而动摇，不给客户虚假希望。
- **推荐草稿**：
  > “亲，实在不好意思！涉及设计院资质盖章、注册师签字以及结构荷载/专业力学计算的图纸，按规定必须由具备法定资质的设计单位出具，我们线上画图工作室无法承接这类业务哦。建议您找当地正规设计院办理，以免耽误您的工程报审，祝您项目顺利！”
