# Pitch Deck 场景规则 (继承 officecli 基座 + 融资层)

## 身份
路演 PPT = pptx + 融资层: VC 叙事弧线、可验证指标、阶段数据密度、创始人可信度面。

## 硬性规则 (继承基座)
- 视觉底线: title >= 36pt / body >= 18pt / title >= 2x body; 12 列网格 (33.87x19.05cm)
- 4 个规范调色板; connector canon (shape/from/to/tailEnd=triangle)
- 每页承载**一个可投资命题** — "有趣背景但不动 ask 前进"的页删掉

## 10 个关键页配方
cover / problem / solution / market / product / model / traction / team / financials / ask

## 融资专属
- stage 诊断 (A/B/C): 决定数据密度
- 数字惯例: $35M / $1.2B TAM 需单引号转义
- VC 船检 (ship-check): 指标可验证
- Delivery Gate 6 (fresh eyes): 换新视角审查
